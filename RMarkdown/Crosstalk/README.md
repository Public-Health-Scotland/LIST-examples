# Crosstalk

This directory provides functional examples of interactive data visualisations built with RMarkdown and Crosstalk.

Crosstalk enables cross-widget interactions, such as linked brushing and filtering, entirely within a standard HTML document. 

## Files

* `practice_filter_crosstalk_example.Rmd`: The foundational RMarkdown script demonstrating the setup and syntax.
* `practice_filter_crosstalk_example.html`: The rendered output, allowing you to test the interactive elements.

## Prerequisites

* `{rmarkdown}`
* `{crosstalk}`
* `{htmltools}`
* `{DT}` or `{plotly}` (for the visual rendering)
