A collection of best practice examples for use by LIST team members.

 * A Git / GitHub initial setup guide - [set-up-GitHub.md](set-up-GitHub.html)
 * [Geospatial examples](Geospatial/)
 * [SMRA examples](SMRA/)

## Using the examples
The simplest (and recommended) way to use these examples is to copy and paste the code as needed, into your scripts.

All scripts are available in readable format on this website, and you can also [view the source files on GitHub]({{ site.github.repository_url }}).

## Navigation
Use the **Table of Contents** in the sidebar to navigate through all available examples, including:

- **Setup Guides**: Git and GitHub configuration
- **Geospatial Examples**: Interactive maps and travel time analysis 
- **SMRA Examples**: Database extraction scripts
- **R Markdown Examples**: Interactive visualizations with Crosstalk
